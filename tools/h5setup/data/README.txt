OSIRIS - the Halo 5 campaign, offline, built from your own Halo 5: Forge and Halo 5: Guardians dumps
====================================================================================================

PLAYING ON WINDOWS
  Run Osiris.exe in this folder. A controller is recommended. It starts fullscreen; Alt+Enter switches to a window.

QUITTING
  Hold View + LB + RB (Back + both bumpers; Share + L1 + R1 on a PlayStation controller) for 3 seconds, or press Alt+F4.

FRAME RATE AND FIELD OF VIEW
  Settings > Audio & Video adds 144 and 180 FPS frame rate choices and a campaign field of view slider (60-120).
  Main menu > Campaign > Solo. Missions unlock as you play, as on Xbox.

PLAYING ON A PS5
  Install the Osiris PS5 app (PPSA99905, from Osiris-PS5-<version>.zip) and copy the contents of
  this folder to /data/halo5campaign/Halo5Campaign on the console. The app's README.txt has the steps.

NO ACCOUNT, NO NETWORK
  Everything runs offline. You play as "Spartan". Online modes (matchmaking, Forge sharing, file share) don't work.

SAVES AND SETTINGS
  Saved in h5campaign\profile inside this folder, so they move with it. Back up that folder to keep your progress.

LOGS (for bug reports)
  h5campaign\logs\game.log      this session            h5campaign\logs\game-prev.log   the one before
  h5campaign\logs\launcher.log  startup

OPTIONS
  h5campaign\settings.ini (see the comments inside).

KNOWN ISSUES
  - In some cutscenes (Glassed and Reunion openings) characters' faces render black (eyes and teeth only).
  - A few sound effects that never shipped in Guardians' own files stay silent.
